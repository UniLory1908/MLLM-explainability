Interpretation

Parseable: the output can be converted into a point or rectangle. Target strong: strong quantitative evidence for the intended COCO object. Valid other object: another annotated object is clearly hit. Ambiguous: label mapping, clipping, multiple instances or evidence conflicts prevent a confident decision. Background or wrong: no meaningful overlap with target or any annotated object.

IoU can penalize a small generated box inside a large object, so model-box precision, target coverage, center-inside and mask overlap are reported too. This validates generated coordinate output, not TAM causal faithfulness.
