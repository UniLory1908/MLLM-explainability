PROJECT CONTEXT
The broader project studies explainability in vision-language / multimodal LLMs, with emphasis on:

Our subtopic is PROMPT ABLATION:
We want to study how prompt interventions affect:
1) the overall quality of MLLM outputs, and

The main technical anchor is Token Activation Map (TAM)-style token-level visual explanation for MLLMs, especially around prompt/context effects on grounding. Priority models/settings include Qwen2-VL, LLaVA-1.5, and InternVL2.5, but relevant broader MLLM/VLM work should also be included.
